# MultiMart – Multi-Vendor E-Commerce Platform

MultiMart is a web-based e-commerce platform designed to bring multiple sellers and products together in one place.

## Features

- Product browsing and categories
- Product search
- Wishlist
- Shopping cart
- Multi-vendor platform structure
- Responsive user interface

## Technologies Used

- React.js
- Vite
- CSS
- Node.js

## Project Structure

- `frontend/` – User interface
- `backend/` – Server-side application
